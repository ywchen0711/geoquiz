# 地理大挑戰

地理問答遊戲：看地圖認國家、在地圖上點出國家、國旗、首都、台灣縣市和地理常識，有四個難度。

**線上玩：** https://ywchen0711.github.io/geoquiz/

## 題目

| 主題 | 題型 |
|---|---|
| 綜合 | 下面全部混在一起 |
| 世界地圖 | 地圖上亮起來的是哪一國（放大到那一洲）、在地圖上點出某國、某國在哪一洲 |
| 國旗 | 看國旗猜國家、四面國旗裡找出某國的 |
| 首都 | 某國的首都是哪裡、某個首都是哪一國的 |
| 台灣 | 地圖上亮起來的是哪個縣市、在地圖上點出縣市（金門、馬祖在小框裡）、景點在哪個縣市 |
| 地理常識 | 山、河、海、湖、海峽、名勝古蹟 |

## 難度

| 難度 | 內容 |
|---|---|
| 簡單 | 有名的國家，四選一，每題 20 秒 |
| 普通 | 更多國家，加上在地圖上點，每題 15 秒 |
| 困難 | 全世界 196 國，錯的選項都是同一洲的鄰國，多了「首都是哪國的」，每題 15 秒 |
| 專家 | 六選一，在整張世界地圖上點，每題 10 秒 |

答對得 100 分，再加上越快越多的速度分、連對加分，乘上難度倍數。每個主題和難度各自記最佳紀錄。題數可選 10、20、30 題；鍵盤可按 1～6 作答、Enter 下一題。

## 資料

- 世界地圖：Natural Earth 1:110m（[world-atlas](https://github.com/topojson/world-atlas)）
- 台灣縣市：內政部資料（[taiwan-atlas](https://github.com/dkaoster/taiwan-atlas)）
- 國旗：[flag-icons](https://github.com/lipis/flag-icons)
- 國名、首都依外交部用法；有多個首都或首都有爭議的國家不考首都，橫跨兩洲的國家不考在哪一洲。

## 檔案

- `js/data.js`：196 個國家（國名、首都、洲、知名度）、22 個縣市、地理常識題
- `js/quiz.js`：出題（各難度的國家範圍、鄰國當錯誤選項）
- `js/map.js`：用 d3-geo 畫世界地圖和台灣地圖
- `js/app.js`：畫面
- `data/`、`flags/`、`js/lib/`：地圖資料、國旗、d3-geo 與 topojson-client
